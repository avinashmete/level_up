# iOS app

This folder contains the Swift host that embeds the shared Compose Multiplatform
framework produced by the `:shared` Gradle module.

The Xcode project itself is **not** committed (its `project.pbxproj` is generated and
contains absolute paths). To create it the first time:

## 1. Build the shared framework

From the repo root:

```bash
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64   # Apple Silicon simulator
# or, for Intel Macs / older simulators:
./gradlew :shared:linkDebugFrameworkIosX64
```

This produces `shared/build/bin/ios{Arm64|X64|SimulatorArm64}/debugFramework/shared.framework`.

## 2. Create the Xcode app

In Xcode (16+):

1. **File → New → Project → App** (iOS).
2. Product Name: `LevelUp`.
3. Interface: **SwiftUI**, Language: **Swift**.
4. Save the project **inside** `iosApp/` (replace the empty `iosApp/iosApp/` files with the
   ones generated by the wizard, *then* drop the existing `iOSApp.swift` and
   `IOSBackupBridge.swift` back in so the Compose entry stays).

In the project's **Build Phases**:

1. Add a **New Run Script Phase** before "Compile Sources":

    ```bash
    cd "$SRCROOT/.."
    ./gradlew :shared:embedAndSignAppleFrameworkForXcode
    ```

2. In **Build Settings**:
   - Add `$(SRCROOT)/../shared/build/xcode-frameworks/$(CONFIGURATION)/$(SDK_NAME)` to
     **Framework Search Paths**.
   - Add the same path to **Header Search Paths**.
3. Link `shared.framework` from that path under **Frameworks, Libraries, and Embedded Content**.

## 3. Run

Pick an iPhone simulator (iOS 16+), hit ⌘R. The Compose UI shows up inside a UIKit
`UIViewController` and routes file picker calls through `IOSBackupBridge`.

## Alternative: KMP plugin

If you would rather skip the manual Xcode setup, install the
**Kotlin Multiplatform** Android Studio plugin and run "Generate iosApp Xcode project"
on the `:shared` module - it produces an equivalent project pointing at the same
framework, but its `.pbxproj` is machine-specific so we keep it out of git.
